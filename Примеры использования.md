Ниже приведены примеры использования методов API к Коннектору Сервера ККМ на C#.

# Ping()
Проверка доступности Сервера ККМ

```csharp
// Создаём коннектор:
using var connector = new SkkmConnector();

//На вход подаем адрес Сервера ККМ:
connector.Address = "localhost";

//Вызываем метод проверки доступности Сервера ККМ:
if (await connector.Ping())
{
    Console.WriteLine($"Название продукта: {connector.Product}");
    Console.WriteLine($"Версия сервера: {connector.ServerVersion}");

}
else
{
    Console.WriteLine($"Код ошибки: {connector.ErrorCode} {connector.ErrorDescription}");
}
```

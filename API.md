# Подключение 
При подключении задается адрес Сервера ККМ, порт используется по умолчанию: 4398. Но его можно задать вручную, указав через двоеточие:
- "localhost:4398";
- "127.0.0.1:4398";
- "<ip-адрес ПК с Сервером ККМ>:4398".

Поле "Token" для методов с авторизацией обязательно только в случае отключения анонимного доступа в настройках Сервера ККМ.
